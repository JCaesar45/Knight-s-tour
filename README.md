## 🚀 Deployment Options

### **Option 1: Static Deployment**
```bash
# Simple static hosting
npx serve .
```

### **Option 2: Full Stack Deployment**
```bash
# Start Python backend
python backend/server.py

# Start Java service
mvn spring-boot:run

# Serve frontend
npm run build
npm start
```

### **Option 3: Docker Deployment**
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```
